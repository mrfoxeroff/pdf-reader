# PDF Reader

Автономный просмотрщик PDF для Windows с интерфейсом в стиле Adobe Acrobat.
Работает полностью офлайн: никаких аккаунтов, облака и телеметрии.

## Установка

Скачайте **`PDFReader-Setup-<версия>.exe`** (≈ 38 МБ) со страницы
[Releases](https://github.com/mrfoxeroff/pdf-reader/releases/latest) и запустите — обычный мастер
установки на русском языке. Python и что-либо ещё не нужны. (Если собираете сами, установщик
появится в локальной папке `dist\`; в репозиторий она не попадает.)

Windows может показать предупреждение SmartScreen, потому что файл не подписан цифровой подписью:
«Подробнее» → «Выполнить в любом случае».

- По умолчанию программа ставится **только для текущего пользователя** и не требует прав
  администратора (в `%LOCALAPPDATA%\Programs\PDF Reader`). В первом окне можно выбрать установку
  **для всех пользователей** (в `Program Files`, понадобятся права администратора).
- Создаются ярлык в меню «Пуск» и, по желанию, на рабочем столе.
- PDF Reader регистрируется в Windows: появляется в меню **«Открыть с помощью»** и в
  **«Параметры → Приложения → Приложения по умолчанию»**. На последней странице мастера есть галочка,
  которая сразу открывает этот раздел, чтобы сделать PDF Reader программой для PDF по умолчанию
  (Windows 10/11 разрешает выбрать программу по умолчанию только самому пользователю).
- Удаление — как у любой программы: «Параметры → Приложения → Установленные приложения → PDF Reader →
  Удалить». Удаляются файлы, ярлыки и все записи в реестре; ваши настройки (недавние файлы, места
  чтения) остаются в `HKEY_CURRENT_USER\Software\PDFReader\PDFReader`.
- Обновление: просто запустите установщик новой версии поверх старой (если программа открыта,
  установщик предложит её закрыть).

Есть и портативный вариант без установки — один файл `PDFReader-portable.exe` (тоже в Releases)
(собирается командой `build.bat portable`).

## Возможности

### Просмотр
- **Плавная прокрутка** колесом мыши, клавишами и тачпадом, листание подряд без рывков.
  Анимация синхронизирована с частотой обновления монитора (60, 120, 144, 240 Гц…), позиция
  считается с точностью до физического пикселя. Страницы рисуются в отдельных фоновых процессах,
  поэтому интерфейс не подвисает даже на тяжёлых файлах.
- **Чёткое изображение при любом масштабе:** страница выводится на экран пиксель в пиксель, без
  промежуточного масштабирования (учитывается и масштаб Windows 125%/150%).
- **Режимы отображения:** одна страница, непрерывная прокрутка, две страницы, две страницы
  с прокруткой.
- **Масштаб** от 8% до 6400%: «по ширине», «страница целиком», «реальный размер», Ctrl + колесо
  мыши (масштаб вокруг курсора), ввод значения вручную. При большом масштабе страница рисуется
  плитками, поэтому остаётся чёткой.
- **Вкладки** — можно открыть сразу несколько документов.
- **Миниатюры страниц**, **закладки (оглавление)** документа, переходы по **ссылкам** внутри PDF
  и наружу, **история переходов** «назад/вперёд» (Alt+← / Alt+→).
- **Запоминание места чтения:** при повторном открытии файл откроется на той же странице и с тем же
  масштабом.
- **Прокрутка средней кнопкой мыши**, как в браузере и Acrobat: щелчок колесом включает режим, в котором документ листается в сторону мыши (тем быстрее, чем дальше она от значка-якоря); если кнопку удерживать — режим работает только пока она нажата.
- **Режим чтения** (Ctrl+H), **полноэкранный режим/презентация** (Ctrl+L),
  **автопрокрутка** (Ctrl+Shift+H, скорость — стрелками ↑/↓).
- **Ночной режим** (инверсия цветов страниц) и **тёмная тема** интерфейса.
- Открываются также XPS, EPUB, CBZ, FB2, MOBI, а изображения (PNG, JPG и др.)
  сразу превращаются в PDF.
- Защищённые паролем PDF.

### Поиск
- **Быстрый полнотекстовый поиск.** Сразу после открытия текст всех страниц индексируется в фоне
  (≈ 600 страниц за 2–3 с), после чего поиск по всему документу занимает миллисекунды
  (в тестах: 7 934 совпадения на 600 страницах — 19 мс; книга на 868 страниц — 10 мс).
- Компактная строка поиска (Ctrl+F) со счётчиком «3 из 63» и переходом Enter / Shift+Enter, F3.
- **Расширенный поиск** (Ctrl+Shift+F) — список всех результатов с контекстом, клик переносит
  к совпадению.
- Параметры: с учётом регистра, только слова целиком. Буквы **«е» и «ё» считаются одной буквой**.
- Подсветка всех совпадений на странице, текущее выделено оранжевым.

### Комментарии и разметка
- Выделение текста мышью, копирование (Ctrl+C), выделить всё (Ctrl+A), двойной клик выделяет слово.
- **Выделение цветом**, **подчёркивание**, **зачёркивание** текста.
- **Записки** (стикеры), **текстовые поля**, **рисование от руки**, **прямоугольники и эллипсы**.
- Выбор цвета для каждого инструмента, смена цвета и текста у существующих комментариев,
  **ластик**, отмена последнего комментария (Ctrl+Z).
- Панель **«Комментарии»** со списком всех пометок документа.
- Всё сохраняется в сам PDF в стандартном формате, поэтому пометки видны в Acrobat, браузерах и
  других программах.

### Страницы (как «Систематизировать страницы» в Acrobat)
- Повернуть страницу / весь документ, удалить, переместить страницы.
- Вставить страницы из другого файла или пустую страницу.
- Извлечь страницы в новый PDF (например, `1-3, 5, 8-10`).
- **Объединить** несколько файлов (PDF, изображения и др.) в один PDF.
- Почти все операции доступны из контекстного меню миниатюр (можно выделить несколько страниц).

### Преобразование Word ↔ PDF
- **Word → PDF:** «Файл → Преобразовать → Word → PDF» (или кнопка ⇄ на панели), а также просто
  **открытие** или **перетаскивание** в окно файлов DOCX, DOC, RTF, ODT, TXT, HTML — документ
  преобразуется и открывается новой вкладкой; сохраните его через «Сохранить как».
- **PDF → Word (DOCX):** «Файл → Преобразовать → PDF → Word» для открытого документа (учитываются
  несохранённые комментарии и защищённые паролем файлы). После преобразования можно сразу открыть
  результат в Word или показать его в папке.
- Конвертер выбирается автоматически:
  1. **Microsoft Word**, если установлен, — наилучшее качество, все форматы Word;
  2. **LibreOffice**, если установлен;
  3. **встроенный** (без внешних программ): DOCX/TXT/HTML → PDF с сохранением заголовков,
     жирного/курсива, списков, таблиц и картинок; PDF → DOCX с абзацами, шрифтами, размерами,
     стилями, цветом и изображениями (страница PDF = страница Word). DOC/RTF/ODT встроенный
     конвертер не читает — для них нужен Word или LibreOffice.
- Преобразование идёт в отдельном процессе с индикатором; «Отмена» корректно закрывает и Word.

### Обновления
- Программа сама проверяет новые версии на GitHub (при запуске и каждые 6 часов, запрос занимает
  доли секунды). Если вышла новая версия, под панелью инструментов появляется уведомление:
  **«Обновить»**, **«Отложить»** (на час / до завтра / на неделю / пропустить эту версию) и ссылка
  «Что нового?».
- «Обновить» скачивает установщик, проверяет его контрольную сумму SHA-256, предлагает сохранить
  открытые документы, тихо устанавливает обновление и **перезапускает программу**.
- **Скрипт обновления:** ярлык **«Обновить PDF Reader»** в меню «Пуск» или файл **`Update.cmd`**
  в папке программы — запускает обновление без лишних вопросов (с окном прогресса). Если программа
  в этот момент открыта, обновление выполнит уже открытое окно, предварительно предложив
  сохранить документы.
- «Справка → Проверить обновления…» — ручная проверка; там же можно выключить автопроверку.
- Портативная версия обновляется так же: заменяет свой exe новым и перезапускается.

### Прочее
- **Печать** через стандартный диалог Windows (диапазон страниц, текущая страница).
- Экспорт страницы в PNG/JPEG с выбором DPI, экспорт всего текста в TXT.
- Свойства документа (Ctrl+D): автор, даты, версия PDF, размер страниц, защита.
- Перетаскивание файлов в окно, список недавних файлов на главной странице.
- Повторный запуск программы с файлом (например, двойной клик в Проводнике) открывает его новой
  вкладкой в уже запущенном окне.

## Как сделать PDF Reader программой по умолчанию

После установки: щёлкните правой кнопкой по любому PDF → **Открыть с помощью** →
**Выбрать другое приложение** → **PDF Reader** → **«Всегда»**. Либо отметьте соответствующую галочку
на последней странице установщика.

Настройки (недавние файлы, места чтения, тема) хранятся в реестре:
`HKEY_CURRENT_USER\Software\PDFReader`. Чтобы сбросить их — удалите этот раздел.

## Сборка из исходников

Нужны Python 3.11+ (проверено на 3.14) и [Inno Setup 6](https://jrsoftware.org/isinfo.php)
(`winget install JRSoftware.InnoSetup`).

```bat
build.bat
```

Скрипт создаст виртуальное окружение `.venv`, установит зависимости
(`requirements.txt`: PySide6, PyMuPDF, PyInstaller, pywin32, mammoth, python-docx), соберёт программу в папку `dist\PDFReader\`
(`PDFReader.spec`) и упакует её в установщик `dist\PDFReader-Setup-<версия>.exe` (`installer.iss`).
`build.bat portable` дополнительно соберёт однофайловый `dist\PDFReader-portable.exe`.
При смене версии поправьте её в `pdfreader/version.py`, `version_info.txt` и `installer.iss`.

Обновить копию исходников с GitHub (`git pull` + новые зависимости): `update.bat`.

Как выпустить новую версию, чтобы установленные программы её получили: поднимите версию
(см. выше), запустите `build.bat portable` и опубликуйте релиз с тегом `vX.Y.Z`, приложив
`dist\PDFReader-Setup-X.Y.Z.exe` и `dist\PDFReader-portable.exe`:

```bat
gh release create vX.Y.Z dist\PDFReader-Setup-X.Y.Z.exe dist\PDFReader-portable.exe --title "PDF Reader X.Y.Z" --notes "Что нового…"
```

Запуск без сборки:

```bat
.venv\Scripts\python main.py [файл.pdf]
```

Тестовый PDF на 600 страниц (с кириллицей, оглавлением, ссылками и повёрнутой страницей):

```bat
.venv\Scripts\python tools\make_test_pdf.py test_files\big.pdf 600
```

Быстрая проверка собранного exe (откроет файл, сохранит снимок окна и закроется):

```bat
dist\PDFReader\PDFReader.exe test_files\big.pdf --screenshot=shot.png
```

## Как это устроено

| Файл | Назначение |
|---|---|
| `main.py` | Точка входа |
| `pdfreader/app.py` | Запуск, единственный экземпляр приложения (QLocalServer) |
| `pdfreader/mainwindow.py` | Главное окно: меню, панель инструментов, вкладки, режимы |
| `pdfreader/doctab.py` | Вкладка документа: боковая панель, просмотр, строка поиска |
| `pdfreader/viewer.py` | Виджет страниц: раскладка, плавная прокрутка, плитки, мышь и инструменты |
| `pdfreader/frameclock.py` | Кадровый таймер, синхронизированный с монитором (DwmFlush) |
| `PDFReader.spec`, `installer.iss` | Сборка программы (PyInstaller) и установщика (Inno Setup) |
| `pdfreader/document.py` | Модель документа: аннотации, операции со страницами, сохранение |
| `pdfreader/pool.py`, `worker.py` | Фоновые процессы для рендеринга и извлечения текста |
| `pdfreader/renderer.py` | Кэш плиток и миниатюр |
| `pdfreader/search.py` | Поисковый индекс и поиск |
| `pdfreader/panels.py` | Миниатюры, закладки, комментарии, результаты поиска |
| `pdfreader/theme.py`, `icons.py` | Светлая/тёмная тема, встроенные SVG-иконки |
| `pdfreader/convert.py`, `convertui.py` | Преобразование Word ↔ PDF (Word / LibreOffice / встроенное) |
| `pdfreader/updater.py`, `updateui.py` | Проверка, загрузка и установка обновлений; уведомление |
| `assets/Update.cmd`, `update.bat` | Скрипт обновления установленной программы / копии исходников |

Почему отдельные процессы: библиотека MuPDF (через PyMuPDF) не отпускает GIL во время отрисовки,
поэтому рендер в обычном потоке «подвешивал» бы интерфейс. Два-три процесса-воркера рисуют
страницы параллельно на разных ядрах, а интерфейс только показывает готовые картинки.
Пока чёткая версия страницы готовится, показывается уменьшенная — пустых страниц при быстрой
прокрутке не бывает. Устаревшие запросы (страницы, которые уже пролистали) отбрасываются.

Плавность: обычный таймер анимации Qt работает на ~60 Гц, что на мониторах 120/144 Гц выглядит
рывками. Отдельный поток вызывает `DwmFlush` — функцию Windows, которая ждёт следующего кадра
композитора, — и на каждый кадр монитора прокрутка продвигается на нужное расстояние, а страница
сразу перерисовывается.

Чёткость: размер страницы в раскладке вычисляется по тем же правилам округления, что и у MuPDF,
поэтому готовая картинка выводится 1:1, без пересэмплирования.

Обновление: программа читает `releases/latest` публичного API GitHub, скачивает установщик и
сверяет SHA-256 с указанным на GitHub. Затем скрытый PowerShell-помощник ждёт закрытия программы,
запускает установщик с `/VERYSILENT /RELAUNCH=1` в ту же папку и тем же режимом
(для пользователя / для всех), а установщик в конце запускает новую версию.

Поиск: текст всех страниц один раз извлекается в фоновом процессе в индекс в памяти,
запрос выполняется регулярным выражением по этому индексу. Координаты подсветки вычисляются
только для видимых страниц.

## Ограничения

- Нет распознавания текста (OCR): в отсканированных PDF без текстового слоя поиск ничего не найдёт.
- Поля интерактивных форм отображаются, но не редактируются; цифровые подписи не проверяются.
- Портативный однофайловый exe при запуске распаковывается во временную папку, поэтому стартует
  медленнее установленной версии.
